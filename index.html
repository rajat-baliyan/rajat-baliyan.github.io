Consultation booking system

Replaced manual scheduling between calling agents and expert advisors.

Role
Owner: spec, build, rollout
Stack
n8n · Google Calendar · WhatsApp API · Sheets · Slack
Users
Pre-sales agents, 3 advisors
Problem

Agents booked homeowner consultations by hand from calendar links and WhatsApp. That caused double bookings, missed reminders and no single record of what was scheduled.

What I did
  • Built a booking page that shows each advisor's live availability from Google Calendar.
  • One click creates the meeting, sends WhatsApp confirmation and 1-hour / 5-minute reminders, logs the CRM row and alerts Slack.
  • A sync job picks up reschedules and cancellations every 10 minutes; high-intent leads get held priority slots.
Result

Manual scheduling removed for 3 advisors. Every booking now has one record, automatic reminders and an owner. Booking rules were later tuned using the no-show analysis below.

Root cause analysis

Why consultations were no-shows

Two weeks of meetings, one dashboard number that looked alarming.

Role
Analysis and recommendations
Data
91 meetings, 2-week window
Tools
Google Sheets · Python · CRM data
Problem

Only 43% of booked consultations showed as completed. The team assumed homeowners were not interested.

What I did
  • Checked data quality first: 36 of 52 "no-shows" were meetings whose status was never updated.
  • Split show-up by how far ahead the meeting was booked, by agent, by time slot and by webinar watch time.
  • Found that only lead time and 60+ minutes of webinar watch time predicted show-up.
Result

Booking window cut to the next working day, a status-update nudge added, and later an automated confirmation call 30 minutes before each meeting.

Program & event operations

Webinar program, registration to sale

The main lead source for the expert-consultation program.

Role
Ran operations and reporting
Scale
22+ events · 4,100+ registrations
Tools
WhatsApp API · Voice · Email · Sheets
Problem

Most registrants never joined, and nobody could see where people dropped between registering, attending, booking a consultation and buying.

What I did
  • Re-sequenced WhatsApp, voice and email reminders and used one tracked join link.
  • Built a nightly funnel: registered → attended 30+ min → consultation → converted, plus cohort analysis across 28+ webinars.
  • Tested a registration cut on small homes: meetings stayed at ~11% of registrants, so I showed the real disqualifier was construction already started, which led to a form change.
Result

Attendance rose from ~35% to a peak of 71%. Leadership now reviews one funnel view every morning instead of asking for numbers.

Daily team reporting and support summaries

Numbers and issues reach the team without anyone compiling them.

Role
Designed and built
Cadence
2 PM status · 8 PM summary · nightly report
Stack
n8n · Call-log API · OpenAI · Slack · Sheets
Problem

Managers asked agents for call counts and meeting status several times a day. Support issues lived in chat threads and were lost by evening.

What I did
  • Mid-day and end-of-day reports per agent: calls, connected, talk time, meetings booked and done, with a 2-week trend chart.
  • An 8 PM AI summary of the day's support issues that I approve or edit before it posts to the team channel.
  • Kept reports in a sheet tab and sent only a short summary to Slack, after feedback that alerts were crowding the channel.
Result

No more manual status requests. Every customer-facing or team-wide message from automation passes a human check first.
